# Bank Branch Network

## Project Overview
This project is a simulated Bank Branch Network designed using Cisco Packet Tracer. It demonstrates the networking infrastructure of a bank, connecting multiple branches with reliable and secure communication.

## Objectives
- Design a bank network infrastructure.
- Configure routers and switches.
- Implement IP addressing and routing.
- Establish communication between bank branches.
- Simulate a real-world banking network environment.

## Tools Used
- Cisco Packet Tracer
- Cisco Routers and Switches
- Networking Protocols

## Project File
`Bank_Branch_Network.pkt`

This project is part of my networking portfolio, demonstrating practical knowledge of network design, configuration, and troubleshooting.
